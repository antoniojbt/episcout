# Figure Checklist

Apply this checklist to package plots, charts and report graphics. Verify analytical truth before refining aesthetics.

## Blocking checks

- [ ] Confirm that the delivered figure answers the requested visual or analytical end goal, not merely the comparison most convenient for the available data or plotting implementation.
- [ ] Reconcile plotted data, filters, transformations, denominators and summaries against verified analysis outputs or source data.
- [ ] Confirm that the chart type and visual encoding represent the intended comparison without distorting magnitude, time, uncertainty or grouping.
- [ ] Check axes, scales, limits, baselines, units, labels, legends, categories, ordering, time periods and sample definitions.
- [ ] Display uncertainty, missingness, suppression, small counts or incomplete coverage when omission could mislead.
- [ ] Ensure annotations, reference lines, labels and captions are supported by the plotted data and evidence.
- [ ] Render and inspect the exact delivered figure at its intended size and within its report or vignette when applicable.

## Quality checks

- [ ] Check type sizes, line weights, point sizes, spacing, aspect ratios and visual hierarchy.
- [ ] Use colour deliberately, maintain sufficient contrast and avoid relying on colour alone.
- [ ] Remove decoration and precision that do not aid interpretation while retaining necessary context.
- [ ] Check clipping, overlaps, empty panels, whitespace, raster quality, file format and consistency across a figure set.
- [ ] Provide a concise title or caption that states what is shown without overstating the conclusion.

## Evidence to report

Report the data object or source reconciled, rendered file inspected, important visual decisions, accessibility limitations and unresolved presentation risks.

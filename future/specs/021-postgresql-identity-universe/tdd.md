# Test Design

Spec ID: `021-postgresql-identity-universe`

Status: Accepted for implementation

## Test Files

- `tests/testthat/test-sec-identity-universe.R`
- `tests/testthat/test-sec-identity-universe-postgres.R`

## Independently Derived Fixture

Use two neutral synthetic sources. Source A has valid identifiers `{A, B, B, C}` and source B has `{B, C, D}`. Independent set arithmetic gives source distinct counts 3 and 3, duplicate excess 1 and 0, union 4, single-source 2, multi-source 2, intersection 2, source-exclusive counts 1 and 1, and directional coverage 2/3 in both directions. A second fixture adds one null, one blank and one regex-invalid value and must block with separate counts. No expected value is generated by production SQL.

## Behaviour Tests

- [ ] Valid reviewed metadata is normalised, sorted and fingerprinted deterministically without row values.
- [ ] Audit returns the fixed source, namespace, pairwise overlap, issue and metadata schemas with independently derived values.
- [ ] Audit transaction is read-only and leaves source and destination catalogues unchanged.
- [ ] Materialisation creates exactly one row per namespace/canonical identifier, a unique constraint, minimum membership counts, no `PUBLIC` privileges and no source changes.
- [ ] The materialised table can be described as a later explicitly reviewed enrolment source without generating registry rows or pseudonyms.

## Edge-Case And Failure Tests

- [ ] Fewer than two sources, mixed namespaces, duplicate relations, unconfirmed provenance, extra columns, unsupported normalisation and malformed regex contracts fail safely.
- [ ] Missing relation/column, unsupported or incompatible types, nondeterministic text collation, caller transaction and unsafe output schema fail with value-free messages.
- [ ] Null, blank, invalid and collision findings block; duplicates warn deterministically; empty sources warn and reconcile to zero.
- [ ] Existing destination blocks with no replacement.
- [ ] A held advisory lock times out without writes or leaked locks.
- [ ] A forced post-create failure rolls back the destination completely.
- [ ] Captured conditions, print output and ordinary result character fields exclude every synthetic identifier value.

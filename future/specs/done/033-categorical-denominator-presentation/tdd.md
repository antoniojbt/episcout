# Test Design

Spec ID: `033-categorical-denominator-presentation`
Status: Completed

## Independent Fixture

Use a hand-authored seven-row categorical fixture stratified by `arm`: three `A` rows, three `B` rows, one missing-stratum row and a declared empty `C` group. The displayed `status` variable contains declared `no`, `yes`, `unused` and zero-count `never` levels, unexpected `other`, one ordinary `NA` and one declared missing code. Expected counts, denominators and proportions are literal test values and are not generated by production helpers.

Expected compatibility examples are `A/yes = 1/2`, `A/missing = 1/3`, `B/other = 1/2`, `Overall/yes = 2/5` and `Overall/missing = 2/7`. Expected column examples are `A/yes = 1/3` and `Overall/yes = 2/7`. Expected row examples are `A/yes = 1/2`, `B/yes = 1/2`, `Overall/yes = 2/2`, missing-stratum/unused `= 1/1`, and every zero-denominator `never` cell has `proportion = NA_real_`. Expected overall examples include `A/yes = 1/7`, `B/other = 1/7` and `Overall/missing = 2/7`.
